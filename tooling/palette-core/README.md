# @mndw/palette-core

Shared TypeScript palette math and contract metadata.

## Part of mndw

mndw is a modular web dashboard for Keenetic/Netcraze routers. Everything in it is a plugin: a dashboard widget or a full page. See [the plugin author site](https://eralde.github.io/mndw/).

## Use

Installed automatically as a dependency of `@mndw/sdk`, `@mndw/cli`, and repository palette build tooling; plugin authors do not use it directly. It exports palette generation, contrast, color conversion, and contract metadata helpers.
