# @mndw/cli

The `mndw` command creates, validates, packs, and runs development sessions for MNDW plugins.

```sh
npm i -D @mndw/cli
npx mndw create my-widget
cd my-widget
npx mndw dev --addr http://router.lan
```

See the [plugin author site](https://eralde.github.io/mndw/) for tutorials,
validation, packaging, and local development details.
